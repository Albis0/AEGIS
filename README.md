# JARVIS

A personal AI assistant desktop app built with Electron, React, and Groq.

## Setup

```bash
npm install
```

Create a `.env` file:

```
GROQ_API_KEY=your_api_key_here
```

## Usage

```bash
npm run dev       # development
npm run electron:build  # production build
```

## Built with

- Electron · React · TypeScript · Vite · Tailwind CSS · Groq SDK
