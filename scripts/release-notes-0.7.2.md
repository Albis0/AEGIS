# AEGIS v0.7.2 — First Public Release

> ⚠️ **AEGIS is under active development.** Not everything works perfectly yet — some tools and features may be unreliable or incomplete. Known issues are tracked and fixed incrementally with each version bump. Treat this as an early-stage project, not a finished product. Bug reports and PRs are very welcome.

A privacy-first desktop AI assistant for Windows — speech recognition, multi-LLM support, and hundreds of tools to control your system, media, smart home, and productivity.

## ⬇️ Download

| File | For whom |
|---|---|
| **AEGIS-Setup-0.7.2.exe** ⭐ **(recommended)** | Regular users — install wizard, Start-menu + desktop shortcut, auto-update |
| AEGIS-0.7.2.exe | Portable — a single file, no installation |

## ✨ Highlights

- **Multi-provider chat:** Groq, OpenAI, Anthropic, Gemini, xAI, DeepSeek, Mistral, Ollama
- **Voice:** microphone → transcription, TTS (Edge / ElevenLabs / Kokoro offline), wake-word, VAD
- **System & apps:** PowerShell, volume/brightness, windows, Spotify, Steam, smart home (Home Assistant)
- **Web, files, vision & computer-use:** search, file management, screenshot analysis, mouse/keyboard control
- **Memory & automation:** facts/habits, scheduled tasks, macros, routines, agent mode
- **16 skins, 5 languages** (Turkish, English, German, French, Spanish)
